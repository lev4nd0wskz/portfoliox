LEO DOS GURI — PORTFOLIO

Como abrir:
1. Extraia o ZIP.
2. Abra index.html no navegador.

Arquivos:
- index.html: estrutura e conteúdo
- style.css: visual responsivo e animações
- script.js: menu mobile, ano automático e animações de entrada

Personalização:
- Troque os textos dos projetos em index.html para refletir o estado atual deles.
- O link guns.lol/leodosguri já está conectado nos botões.
- As fontes são carregadas do Google Fonts; sem internet, o site usa fontes alternativas.
- Não precisa de Node.js, npm ou servidor para funcionar.
